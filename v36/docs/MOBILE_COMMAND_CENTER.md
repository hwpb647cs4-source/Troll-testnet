# TROLL NFT 2.0 — V36 Mobile Command Center

V36 is built specifically for phone/iPad operation while desktop-only security tooling is pending.

## What it does
- opens the Live Passport;
- opens Collection Intelligence;
- opens Release Control;
- opens the V14 testnet launcher;
- reads the current release manifest;
- reads the canonical security findings register;
- shows the frozen V19 candidate;
- shows Codex Security as pending desktop connection;
- shows the independent human audit as open;
- keeps mainnet visibly blocked.

## What it does not do
- no wallet connection;
- no signature request;
- no transaction;
- no deployment;
- no private key/seed phrase;
- no release authorization.

## Offline behavior
The shell is installable as a small PWA and caches the basic command-center files. Live release/security data still requires network access to refresh.

## Operational rule
Phone-only availability must never become a reason to weaken security. Desktop-only Codex Security can remain pending while read-only/product/business layers continue.
