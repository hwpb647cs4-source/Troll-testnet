# 2026 Arbitrum Open House / Robinhood Chain — Buildathon Pitch

## Project
TROLL NFT 2.0

## Category
RWA infrastructure / NFT identity / programmable wallet / AI-native application

## Problem
NFT ownership typically transfers a picture and metadata, while financial history, utility state and wallet context are fragmented across separate systems.

## Solution
A persistent NFT identity that carries:
- immutable family provenance;
- burn-driven evolution;
- a deterministic protected vault;
- separated regulated entitlements;
- a verifiable accumulation biography;
- a public Live Passport;
- human-controlled agent preparation.

When the NFT changes owners, the token-ID biography remains intact.

- exact chain + contract asset identity;
- explicit evidence labels;

- event-sourced indexer;
- deterministic proof bundles;
- default-deny agent policy;
- machine-readable release gates.
