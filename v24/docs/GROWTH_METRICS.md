# V24 Growth Metrics

The goal is to prove useful growth rather than manufacture market activity.

## Protocol usage
- minted NFTs
- unique holders
- vaults created
- cumulative TROLL burned
- evolution-state distribution
- reward epochs
- direct-vault asset deposits
- regulated entitlements
- secondary transfers
- agent simulations
- owner-signed agent actions

## Product usage
- unique passport viewers
- passport views/token
- SDK requests
- API consumers
- marketplace integrations
- wallet integrations
- developer projects using the SDK

## Business
- primary mint revenue
- creator royalties actually received
- grants received
- B2B integration revenue
- subscription/analytics revenue
- infrastructure cost
- audit/security cost

## Never count as business revenue
- nominal NFT floor value
- nominal vault-token market value
- unrealized stock/token gains
- wash volume
- self-transfers
- subsidized fake activity

## North-star metric

**Verified Useful Value per Active Holder**

A composite operational metric can include:
- protocol usage;
- verified assets/entitlements;
- number of meaningful stamps;
- passport engagement;
- agent utility;
- integrations.

It must not be presented as an investment-return score.
