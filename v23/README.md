# V23 Live Value Passport

V23 upgrades the V22 static example into a live read-only Robinhood Chain Testnet passport.

It reads current owner, family, collection supply, provenance hashes, evolution engine, metadata router, token URI, cumulative TROLL burn, evolution state, reward weight and latest block directly from the chain.

The V14 full-testnet vault/reward values for token #0001 remain explicitly labeled as **historical proof snapshot evidence** until each exact reward-token contract address is configured and queried live. This prevents historical test evidence from being displayed as current financial value.

V23 adds no Solidity and does not modify the frozen V19 review target.
