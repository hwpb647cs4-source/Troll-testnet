# TROLL NFT 2.0 — V29 Proof-of-Accumulation Timeline

V29 unifies the existing identity, event-index, reward-ledger and passport evidence into one chronological biography per NFT.

## Timeline event classes
- MINT
- FAMILY_VERIFIED
- TROLL_BURN
- EVOLUTION
- VAULT_CREATED
- REWARD
- REGULATED ENTITLEMENT
- STAMP
- TRANSFER
- AGENT

Every event keeps its evidence label and reference.

## Collector experience
A holder can see a simple chronology such as:

**Minted → NVIDIA family verified → Vault created → 10K TROLL burned → Awakened → 165K additional TROLL burned → Ascended → Gold proof recorded → Silver proof recorded → NVDA entitlement recorded → NFT transferred → history preserved.**

The chronology moves with the NFT's token-ID identity; it is not erased when ownership changes.

## Reward Epoch Engine — accounting stage
V29 also defines deterministic epoch manifests.

An epoch manifest:
- identifies the chain;
- lists exact token IDs and asset contracts/references;
- specifies raw units and decimals;
- specifies evidence class;
- rejects duplicate allocation identities;
- produces a canonical SHA-256 hash.

This is an accounting/proof engine only. It does not automatically distribute assets and does not promise future rewards.

## Why this matters
The NFT becomes easier to understand as a persistent digital object with a verifiable history. Collectors can distinguish actual on-chain state, regulated entitlements, historical proofs and reference-only themes without mixing them.

## Security
V29 adds no Solidity, no custody, no wallet signing and no transaction broadcast. V19 remains frozen.
