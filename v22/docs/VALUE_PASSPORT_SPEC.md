# TROLL NFT 2.0 — V22 Value Passport

V22 does **not** change the frozen V19 contract core.

It adds a read-only product layer that makes each NFT's verified history easier to understand, compare and collect.

## Principle

> **Value should come from verified utility, history and accumulated assets — not promises.**

The passport never claims guaranteed appreciation, guaranteed yield or guaranteed redemption.

## Passport sections

### 1. Immutable identity
- token ID
- Genesis Series I
- permanent family
- Genesis rarity
- frozen trait vector
- Genesis manifest hash
- family Merkle root

### 2. Evolution biography
- cumulative TROLL burned
- current evolution state
- current reward weight
- evolution milestones with block/timestamp evidence

### 3. Persistent vault
- bound-vault address
- exact-chain/exact-contract holdings
- approved asset classes
- first-seen block
- latest verified snapshot
- reward-epoch history

### 4. Regulated entitlements
Stock/tokenized-security-like benefits remain visibly separated from freely transferable vault assets.

The UI must distinguish:
- **DIRECT VAULT ASSET**
- **REGULATED ENTITLEMENT**
- **REFERENCE THEME ONLY**

### 5. Ownership biography
- mint timestamp
- current holder-since
- transfer count
- previous ownership events
- no reset of family/evolution/vault relationship on sale

### 6. Agent readiness
- operating account present / absent
- agent policy enabled / disabled
- simulation required
- human signature required

## Evidence-backed stamps

Stamps are **derived badges**, not financial promises.

Examples:
- GENESIS I
- FAMILY VERIFIED
- AWAKENED
- CHARGED
- RELIC
- ASCENDED
- LEGENDARY
- OMEGA
- VAULT CREATED
- FIRST REWARD
- GOLD HELD
- SILVER HELD
- STOCK ENTITLEMENT
- MULTI-ASSET VAULT
- OWNERSHIP TRANSFERRED
- HISTORY PRESERVED
- AGENT READY
- SNAPSHOT VERIFIED

Every stamp must have:
- a deterministic derivation rule;
- supporting contract/event/block evidence;
- no admin-only manual award path.

## Display hierarchy

The passport should make one thing obvious in under five seconds:

**What is this NFT, what has it done, what does its wallet contain, and which facts are independently verifiable?**
