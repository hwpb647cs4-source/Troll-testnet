# Final V19 Testnet Deployment

This is deployment-only tooling for the frozen V19 candidate.

Open the published page from an injected EVM wallet browser, switch to Robinhood Chain Testnet (46630), load the CI build, deploy, then run the proof.

The page never requests or stores a private key/seed phrase. Transactions are individually confirmed by the wallet.

Mainnet is intentionally unsupported here.
